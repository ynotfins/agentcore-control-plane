# Project Gates

## Milestone 0 bootstrap

Use only for a newly enrolled AgentCore project or an enrolled repository missing governance.

1. Verify the exact enrollment pair, repository root, branch, and inherited Git state.
2. Open the durable session and capture the operator request through the signed lifecycle.
3. Create only missing governance assets from `D:\github\agentcore-control-plane\templates\project-governance\.agentcore`; preserve existing content.
4. Ensure root `AGENTS.md` and `CLAUDE.md` exist and match the Root Agent Rules Template in `MASTER_CONFIG_AND_PROMPT.md`.
5. Establish the project charter, milestones, checklist state, tool manifest, project state, risk register, and acceptance tests through their governed templates.
6. Run repo-local Context Fabric capture/drift if available, inspect architecture with native project tools, resolve external versions through Arabold Docs, and record the bootstrap evidence.
7. Do not auto-enroll, create a new canonical store, write `.env`, or copy machine-global credentials into the project.

## Milestone entry

1. Read authority, generated STATE, current handoff, previous gate evidence, checklist state, and Git identity.
2. Retrieve recent canonical chronology and expand any decision or artifact that controls the Milestone.
3. Confirm the previous Milestone passed and the current acceptance contract is explicit.
4. Audit the tool manifest and obtain only required leases.
5. Capture Context Fabric state/drift at the exact repository root.
6. Break work into evidence-bearing Micro steps and record the entry transition.

## Milestone exit

1. Confirm every Micro step has deterministic evidence and passed acceptance criteria.
2. Run task tests, relevant repository validators, lint/type checks, secret/junk scan, and UI acceptance where applicable.
3. Run Depwire post-change for structural work and semantic diagnostics for symbol-sensitive work. Use other conditional tools only when their task gate applies.
4. Record decisions and final evidence in canonical memory. Never write generated projections directly.
5. Run the governed projection worker, verify the new STATE/DECISIONS/CONTEXT_INDEX revisions, and capture Context Fabric exit state/drift.
6. Build the deterministic handoff, close the session, release expired leases, and push only task-owned source files.

If a required gate cannot be proven, leave the Milestone open and report the missing evidence.
