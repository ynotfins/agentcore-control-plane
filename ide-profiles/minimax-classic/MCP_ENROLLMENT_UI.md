# MiniMax Agent Classic — AgentCore Gateway Enrollment Status

AgentCore gateway enrollment is **unsupported/unverified** for MiniMax Agent
Classic. Classic stores custom MCP configuration through the Matrix cloud catalog,
and no credential-free, native-token, environment-backed, or scoped-broker route is
approved for AgentCore.

Do not create an `agentcore-gateway` custom MCP server and do not paste or persist an
AgentCore virtual key in the Matrix UI or cloud catalog. The repository template is
deliberately inactive.

Historical product identity and application-launch evidence remain valid. Earlier
instructions that proposed cloud enrollment were pending work and are now classified
as legacy evidence rather than an approved action. Any unexpected existing entry must
be preserved for a separate backup-first audit.
