## Official Documentation Verified

- Zoo Code Codebase Indexing docs: Qdrant is the vector database; embeddings are generated by a configured provider; the resulting `codebase_search` tool is made available to Zoo.
- Zoo Code docs list supported embedding providers including OpenAI, Ollama, OpenAI-compatible, Gemini, Mistral, Vercel AI Gateway, Bedrock, and OpenRouter.
- Zoo Code marketplace docs: global modes are stored in `custom_modes.yaml`; global MCP config is stored in `mcp_settings.json`.
- Qdrant latest GitHub release observed: `v1.19.0`, published 2026-08-05, with `qdrant-x86_64-pc-windows-msvc.zip`.
- Qdrant configuration docs: custom config can be supplied with `--config-path`, storage paths are configurable, environment variables override config, and `service.host`, `http_port`, and `grpc_port` control binding.
- Qdrant security docs: self-hosted deployments are not secure by default; local development should bind to `127.0.0.1`; API keys should be considered with TLS because sending API keys over unencrypted HTTP is insecure.

## Architecture Decision

Zoo Code Qdrant is classified as `REBUILDABLE_DERIVED_CODE_INDEX`. It must not be used as AgentCore memory, project evidence, official docs authority, or canonical NFA source. AgentCore PostgreSQL/pgvector, neutral SwarmRecall, Meilisearch, Cognee, and Arabold remain separate and are not backends for Zoo Code's native code index.
